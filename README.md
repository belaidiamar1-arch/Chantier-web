# Chantier-web

Version web installable de **Chantier**, mon gestionnaire de projets d'applications :
projets, jalons, sous-tâches mises à jour par Claude Code, et espace idées.

👉 **https://belaidiamar1-arch.github.io/Chantier-web/**

Sur iPhone : ouvrir le lien dans Safari → Partager → « Sur l'écran d'accueil ».

Ce dépôt ne contient que l'application. Les données (projets, tâches, idées) sont dans
le dépôt **privé** `Chantier-data`, lu et écrit par l'app grâce à un jeton GitHub
enregistré uniquement sur l'appareil.
